# Documentation Archive

This folder contains historical docs that are still useful for legacy context, prior test passes, and implementation history.

## Why files are archived

Archived files are typically moved here when:
- behavior in code has evolved from the original document
- setup/tooling versions have changed (for example, Expo/React Native upgrades)
- a document is a dated runbook or test artifact rather than current source-of-truth

## Active documentation (use these first)

- `README.md` (current product behavior and setup)
- `docs/CHATGPT_INTEGRATION.md` (current import format and flow)
- `docs/dev_workflow.md` (current dev/test workflow)

## Archived sections

- `specs/` - legacy product specs and build checklists
- `test-guides/` - historical test runbooks and fix instructions

## Notes

- Dated runtime test evidence remains under `docs/test-runs/`.
- Archived docs are not automatically wrong; they may still be useful for background context.
